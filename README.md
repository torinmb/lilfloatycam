# Lil Floaty Cam website

The website for Lil Floaty Cam, served by GitHub Pages at https://lilfloatycam.com/

- `index.html`: the home page
- `support/`: FAQ & Support (`faq/` redirects here)
- `privacy/`: Privacy Policy
- `changelog/`: generated by `Packaging/make_changelog.py` in the app repo when `release.sh` runs (don't edit by hand)
- `assets/`: shared styles (`site.css`), the water and lily pad effect (`water.js`) and images
- `sitemap.xml`: submitted in Google Search Console; `robots.txt` also points crawlers to it

The download links point at the Patreon post. When the Mac App Store version goes live, search for
`patreon.com/blankensmithing/posts/lil-floaty-cam` and swap in the App Store link.

The Sparkle update feed lives separately in [torinmb/lilfloatycam-updates](https://github.com/torinmb/lilfloatycam-updates),
whose old `/support/`, `/privacy/` and `/changelog/` pages redirect here.

## Checking which version is live

Every page has `<meta name="site-version" content="…">` in its head. Run `tools/stamp-version.sh` before committing, then check the live site with:

```bash
curl -s https://lilfloatycam.com/ | grep site-version
```
